1. Core Concept & Signal Architecture

          

            MODULO is a terminal-based algorithmic music environment. A program consists of one global $playback block that controls the master clock and block queue, and one or more block [name] definitions. Each block has its own time signature (meter), a primary voice, and up to 7 parallel layer voices. Every voice has its own dedicated DSP channel strip (Gain, Stereo Pan, Distortion, Chorus, Delay, and Reverb).
          

        


        

          
2. Global $playback Configuration

          
$playback {
  tempo: 118                           // Master tempo in BPM (30..300)
  swing: 0.08                          // Subdivision swing (0.0..0.5)
  sequence: [intro, groove * 4, outro] // Playback queue (* N repeats block N bars)
  loop: true                           // Loop entire queue continuously (true | false)
  repeat: 1                            // Global multiplier applied to all sequence items
}

        


        

          
3. Block Primary Voice & Multi-Layer FX Routing

          

            You can set mix and DSP effect parameters directly on the block for its primary voice, and attach inline pipe modifiers (| key: value, ...) to every layer independently:
          

          
block cyber_math {
  meter: 7/8
  instrument: "sawtooth"
  gain: 0.75
  pan: -0.35
  reverb: 0.45
  delay: 0.30
  distortion: 0.25
  chorus: 0.40
  play: euclid(5, 8, 1) on "c3 g3 a#3 d4"

  // Parallel layers with independent gain, pan, and FX:
  layer: "kick"  | euclid(2, 7) on "c1"          | gain: 1.15, dist: 0.4
  layer: "snare" | euclid(2, 7, 3) on "c2"       | gain: 0.85, reverb: 0.35
  layer: "hat"   | prime(14) on "c5"             | gain: 0.45, pan: 0.6, delay: 0.4
  layer: "fm"    | modulo(14, 3, 1) on "g4+d5"   | gain: 0.6, pan: 0.4, chorus: 0.6, reverb: 0.7
}

        


        

          
4. Available Synthesized Instruments (8 Timbres)

          
    
            
  • "sine" — Pure fundamental sub/melodic sine oscillator.
    • 
            
  • "triangle" — Warm, hollow low-harmonic lead or bass wave.
    • 
            
  • "sawtooth" — Bright harmonic-rich synth brass/lead wave.
    • 
            
  • "square" — Woody odd-harmonic chiptune / hollow synth wave.
    • 
            
  • "fm" — Two-operator Frequency Modulation metallic/bell synthesizer.
    • 
            
  • "kick" — Pitch-enveloped membrane bass drum (use low notes like "c1" or "g0").
    • 
            
  • "snare" — Pink-noise transient snare / clap synthesizer.
    • 
            
  • "hat" — Crisp high-frequency metallic white-noise hi-hat.
    • 
          

        


        

          
5. Mix & DSP Effects Parameters (Primary & Layer)

          
    
            
  • gain: 0.05..1.5 — Output amplitude multiplier (default 0.85).
    • 
            
  • pan: -1.0..1.0 — Stereo panorama: -1.0 hard left, 0.0 center, 1.0 hard right.
    • 
            
  • reverb: 0.0..1.0 — Stereo algorithmic hall reverb send amount.
    • 
            
  • delay: 0.0..1.0 — Dotted-eighth stereo ping-pong echo send amount.
    • 
            
  • distortion: 0.0..1.0 (or alias dist) — Waveshaper overdrive saturation per voice.
    • 
            
  • chorus: 0.0..1.0 — Stereo modulated chorus widening send amount.
    • 
          

        


        

          
6. Mathematical Pattern Generators

          
    
            
  • 
              seq("c3 e3 ~ g3+b3", dur: 1/8) — Step sequence. Supports rests (~ or .) and polyphonic chords joined with + (e.g. c3+d#3+g3+a#3).
            
    • 
            
  • 
              euclid(k, n, rot?) on "notes" — Bjorklund Euclidean algorithm. Distributes k pulses across n steps with optional phase rotation rot.
            
    • 
            
  • 
              modulo(steps, mod, offset?) on "notes" — Modular arithmetic generator. Triggers when (step + offset) mod m == 0 and maps note indices via modular residues.
            
    • 
            
  • 
              fibonacci(n) on "notes" — Fibonacci sequence generator across n steps using golden-ratio-like non-periodic accents.
            
    • 
            
  • 
              cellular(rule30, n) on "notes" — Wolfram 1D Cellular Automaton (rule30, rule90, rule110, rule184). Evolves to a new generation every bar.
            
    • 
            
  • 
              prime(n) on "notes" — Prime number sieve across n subdivisions (triggers on prime steps 2, 3, 5, 7, 11, 13...).
            
    • 
          

        


        

          
7. Live Coding Workflow & Hotkeys

          
    
            
  • Ctrl + Enter (or Cmd + Enter) — Evaluate and hot-reload AST on the fly without interrupting the audio clock.
    • 
            
  • Ctrl + . — Stop playback immediately and release all voices.
    • 
            
  • Tab — Insert 2 spaces of indentation.
